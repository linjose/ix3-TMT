# Changelog

## 2.0.0 - 2026-10-06

Complete rewrite from the original PHP/Bootstrap proof of concept.

### Added
- Django application and admin.
- Deck/Slide-first relational model.
- PostgreSQL and SQLite support.
- PPT/PPTX upload queue.
- LibreOffice + Poppler rendering pipeline.
- Conditional Traditional Chinese + English Tesseract OCR.
- Native PPTX text extraction.
- Local summary and keyword/tag generation.
- Slide knowledge wall and search.
- PostgreSQL `pg_trgm` indexes.
- Star and personal Collections with bookmark notes.
- Contribution analytics and leaderboard.
- Deck visibility and protected slide/original file delivery.
- Docker Compose deployment.
- Ubuntu 24.04, systemd and Nginx deployment examples.
- GitHub Actions test workflow.

### Changed
- Previous PoC files moved under `legacy/`.
